# Multi-Carrier Spread Spectrum (MC-SS) Image Steganography

A spatial-domain image steganography implementation that distributes a secret message across multiple cover images using pseudo-noise (PN) sequences and error-correcting codes.

---

## Overview

In conventional Direct-Sequence Spread Spectrum (DSSS) steganography, the entire secret message is embedded into a single cover image. If that image is heavily compressed, cropped, or dropped during transmission, the entire payload is lost.

This project implements **Multi-Carrier Spread Spectrum (MC-SS)** steganography. The secret message is divided across $N$ separate carrier images (such as standard test images Lena, Baboon, Peppers, and Cameraman). Each sub-message is spread using a distinct, near-orthogonal PN sequence generated by a Linear Feedback Shift Register (LFSR) from a shared secret key. To handle image loss or channel corruption, the data is protected with a Hamming(7,4) code and interleaved across carriers.

---

## Method

The pipeline consists of five stages:

```
Secret Text ──> [Binary Conversion] ──> [Hamming(7,4) Encode] ──> [Carrier Interleaving]
                                                                          │
  ┌───────────────────────── N Sub-streams ───────────────────────────────┘
  ▼
[LFSR / Gold PN] ──> [Spread by M chips & scale by α] ──> [Add to Cover Images] ──> N Stego Images
                                                                                          │
                                                                                          ▼
[Decoded Text] <── [Hamming Decode] <── [De-interleave] <── [Threshold] <── [High-Pass + Correlation]
```

1. **Preprocessing & Error Correction:**
   The secret text is converted into bits with a 32-bit length header. The bitstream is encoded using a Hamming(7,4) block code, where every 4 data bits produce a 7-bit codeword capable of correcting 1-bit errors or resolving up to 2 erasures.

2. **Bit Interleaving:**
   Instead of sending consecutive codeword bits through the same image, the 7 bits of each codeword are distributed across different carrier images. If one carrier image is lost or intercepted, only 1 or 2 bits are missing per codeword, allowing full reconstruction.

3. **PN Sequence Generation:**
   A Linear Feedback Shift Register (LFSR) initialized by a shared seed key produces $N$ near-orthogonal pseudo-noise sequences. The binary output $\{0, 1\}$ is converted to bipolar format $\{-1, +1\}$ so the added signal has zero mean.

4. **Spatial Embedding:**
   Each bit is spread over $M$ pixels (chips), where $M = \lfloor \text{total pixels} / \text{sub-message length} \rfloor$. The spread signal is scaled by an amplitude factor $\alpha$ (typically $1.5$ to $2.0$) and added directly to the cover image pixels in the spatial domain:
   $$I_{\text{stego}}(j) = \text{clip}\left(I_{\text{cover}}(j) + \alpha \cdot b_i \cdot P_k(j),\, 0,\, 255\right)$$

5. **Blind Extraction & Reconstruction:**
   At the receiver, a 3×3 spatial filter estimates and subtracts local image content to reduce host image interference. The residual signal is cross-correlated against the regenerated PN sequence:
   $$C_i = \sum_{j=1}^{M} I_{\text{residual}}(j) \cdot P_k(j)$$
   Bits are determined by sign ($C_i \ge 0 \implies 1$, $C_i < 0 \implies 0$). The recovered streams are de-interleaved, processed through the Hamming decoder, and converted back into text.

## Comparison: MC-SS vs. Single-Image DSSS

| Metric / Feature | Single-Image DSSS (Baseline) | MC-SS (Proposed) |
| :--- | :--- | :--- |
| **Carrier Loss** | 100% payload loss if the image is dropped | 0% BER with 1 dropped carrier (Hamming ECC) |
| **Spreading Factor ($M$)** | $M_{\text{single}} = \text{Pixels} / L_{\text{total}}$ | $M_{\text{mcss}} = N \times M_{\text{single}}$ ($N\times$ higher processing gain) |
| **Imperceptibility** | High noise needed for low error rates | Low amplitude ($\alpha \le 2.0$), PSNR $> 42\text{ dB}$, SSIM $> 0.96$ |
| **Channel Robustness** | Higher error rate under noise/JPEG | Lower BER under AWGN, JPEG, and spatial cropping |
| **Key Sensitivity** | Extraction requires valid key | Extraction requires valid key; wrong key yields BER $\approx 50\%$ |

## Setup and Installation

### 1. Environment Setup

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install the dependencies:

```powershell
pip install -r requirements.txt
```

### 2. Download Cover Images

Download and prepare standard 512×512 test images:

```powershell
python download_dataset.py
```

---

## How to Run

### Interactive Streamlit Interface
Run the local web interface to test custom text, adjust $\alpha$, apply attacks, and view extraction results:

```powershell
streamlit run app.py
```

### Jupyter Notebook
Open the demonstration notebook containing step-by-step code and pre-rendered plots:

```powershell
jupyter notebook demo_showcase.ipynb
```

### Run Benchmarks
Generate the evaluation graphs (PSNR vs. $\alpha$, BER vs. Noise/JPEG, and BER vs. Carrier Loss):

```powershell
python run_benchmarks.py
```
Output images are saved to the `results/` folder.

### Run Unit Tests
Run the test suite to verify the LFSR generator, ECC logic, and embedding pipeline:

```powershell
python -m unittest discover tests
```

## Benchmark Results Summary

Measured on standard 512×512 images (Lena, Baboon, Peppers, Cameraman) with a 632-bit payload:

* **Imperceptibility ($\alpha = 2.0$):**
  * Average PSNR: **42.11 dB** (above the 40 dB threshold)
  * Average SSIM: **0.974**
  * Clean BER: **0.00%**
* **Carrier Loss Resilience ($N = 4$):**
  * 4 of 4 carriers received: **0.00% BER**
  * 3 of 4 carriers received (1 dropped): **0.16% BER** with Hamming ECC (Single DSSS: **100% loss**)
* **Additive Gaussian Noise ($\sigma = 16$):**
  * MC-SS BER: **0.00%**
  * Single DSSS BER: **0.63%**
* **JPEG Compression ($QF = 65$):**
  * MC-SS BER: **1.42%**
  * Single DSSS BER: **8.70%**
